# Никтон — трекер кальяна

Мобильное веб-приложение без сборки и зависимостей: HTML + CSS + чистый JS.

## Запуск

```
python3 -m http.server 8000      # в этой папке
```
Откройте http://localhost:8000 (или с телефона по IP компьютера). Через file:// кадры анимации могут не загрузиться.

При первом запуске история пуста, все счётчики равны нулю. В календаре появляются только ваши отметки; сохранённая история восстанавливается при следующем запуске.
Параметр URL: `?splash=0` — без заставки.

Если в браузере сохранились отметки из старой демоверсии, их можно удалить в консоли на странице приложения:

```js
localStorage.removeItem('nikton.marks.v1');
location.reload();
```

Это удалит всю историю приложения для текущего адреса, включая собственные отметки. Если демоверсию только открывали и не меняли отметки, очищать хранилище не нужно.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас: контейнеры `#main`, `#sheet`, `#data`, `#splash`, SVG-фильтр дыма |
| `styles.css` | все стили, токены цветов в `.app { --… }` |
| `app.js` | логика: состояние `S`, функции `render*`, обработчики (делегирование по `data-act`, `data-day`, `data-view`, `data-month`) |
| `nikton.js` | проигрыватель анимации монстра (см. раздел «Фазы») |
| `assets/` | 54 кадра монстра (WebP) |

## Данные

- Хранение: `localStorage['nikton.marks.v1']` = `{ "YYYY-MM-DD": "clean" | "smoked" }`.
- Экспорт/импорт JSON — **не реализованы**, только интерфейс. Заглушки в `app.js`:
  `exportJson()` и `importJson(file)` (помечены `TODO`). Формат файла: `{ "version": 1, "marks": { … } }`.
  После импорта: `S.marks = data.marks; saveMarks(S.marks); renderMain();`

## Логика

- Серия (`streakAt`) — дни `clean` подряд, заканчивая выбранной датой.
- Текущее состояние (`currentState`): если сегодня отмечено — по сегодня, иначе по вчера.
- Статистика (`stats`) — за всё время: дни без курения, дни курил, самая длинная серия.
- Будущие дни отметить нельзя. Неделя с понедельника.
- Назад можно листать до месяца самой ранней сохранённой отметки; при пустой истории — до текущего месяца. Граница действует для стрелок, свайпов и выбора месяца в годовом обзоре и обновляется при удалении отметок.

Проверка логики календаря: `node tests/calendar.cjs`.

## Фазы анимации

| Серия | Фаза |
|---|---|
| 1 | `phase-1` по кругу |
| 2–3 | `phase-2-3` |
| 4 | `phase-4` |
| 5 | `phase-5` |
| 6 | `phase-6` один раз → `ash` |
| 7+ | `ash` |
| покурил | `smoked` один раз → `phase-1` |

API проигрывателя: `Nikton.mount(el, { phase, assets: 'assets/', loop, onEnd })` → `{ setPhase, play, pause, seek, destroy }`.
Блок держит пропорцию 16:9 и тянется на ширину контейнера (`.stage .host`).

## Маркеры дней

- без курения — мятное кольцо; яркость растёт с серией (`.t2` с 3-го дня, `.t3` с 7-го);
- курил — анимированное облако дыма (SVG `SMOKE_SVG` + фильтр `#smkBlur`);
- сегодня — янтарная черта снизу.
